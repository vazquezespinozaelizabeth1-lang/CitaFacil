\section{Descripción General del Proyecto}
CitaFácil es una plataforma web multipágina enfocada en la gestión eficiente y accesible de citas médicas para consultorios independientes. La interfaz busca maximizar la facilidad de uso, reduciendo la fricción para pacientes de cualquier edad.

\section{Normativa de Diseño Seleccionada}
Se adopta el sistema de diseño Material Design 3 de Google en combinación con las pautas de accesibilidad WCAG 2.2 Nivel AA. Esta integración asegura consistencia visual y accesibilidad universal.
