\section{Paleta de Colores}
La paleta cromática se estructura en torno al tono principal verde azulado (\texttt{\#2F7F7A}), complementado con tonos neutros de alto contraste para garantizar la legibilidad según el estándar WCAG 2.2.

\section{Tipografía}
Se utiliza la tipografía \textbf{Atkinson Hyperlegible} para optimizar la velocidad de lectura e higiene visual en personas con baja visión, manteniendo \texttt{Verdana} como fuente alternativa del sistema.
